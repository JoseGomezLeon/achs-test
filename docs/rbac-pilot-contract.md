# Contrato de trabajo del piloto RBAC

Este repositorio se usa para construir el piloto de RBAC desde una base limpia.

Reglas de trabajo:

1. No implementar reglas de negocio sin ADR aprobado.
2. No mezclar pruebas de otros modulos.
3. Mantener separadas las capas de dominio, aplicacion e infraestructura.
4. Agregar cada tipo de test en su carpeta correspondiente.
5. Documentar cualquier decision nueva junto al ADR.
